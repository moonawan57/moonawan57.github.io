Step-by-Step Deployment Guide (No VS Code, No npm required) Step 1: Create a GitHub Repository Go to GitHub and log in to your account. In the top right corner, click the + icon and select New repository. Name your repository (for example: portfolio). Set the visibility to Public. Do NOT check "Add a README file" (leave all checkboxes blank). Click Create repository. Step 2: Create index.html On your new repository main page, click the link that says creating a new file. Name the file exactly: index.html Step 3: Paste the Complete Code Copy all of the HTML code provided in the box above. Paste it directly into the index.html editor box on GitHub. Step 4: Commit the Changes Scroll down to the bottom of the page to the Commit changes... section. Click the green Commit changes... button. Step 5: Configure GitHub Pages At the top of your repository page, click on the Settings tab (gear icon). In the left sidebar, locate and click on Pages (under the "Code and automation" section). Under Build and deployment, look for Branch. Change the dropdown from None to main (or master). Leave the folder dropdown as / (root). Click Save. Step 6: Open Your Live Portfolio URL Wait about 30 to 60 seconds for GitHub to build your site. Refresh the Pages settings page, and your public website link will appear at the top (e.g., [https://yourusername.github.io/portfolio/](https://yourusername.github.io/portfolio/)). Click the link to view your live, responsive portfolio website!
